EVIDENCE AND SCOPE

让结论，停在证据边界内。

“能智核”定位公共建筑用能异常核验，节能机会筛查作为附属能力。

01

真实用能回放

BDG2 提供真实建筑历史电表与天气数据，用于展示用能变化和参考比较。没有设备故障真值，不参与空调故障定位准确率计算。

实测 · BDG2
02

设备核验验证

LBNL 单风道空调机组为带标签仿真数据。新日期用于时间留出验证；同一仿真系统不等于跨设备或真实建筑验证。

仿真 · LBNL
03

明确保留未决

停机、模式不适用、缺少有辨识力的时间窗，或多种原因无法区分时保留未决。“异常但未定位”不计作三分类正确，未决留在总体分母中。

无充分证据 ≠ 正常
04

核查与节能有距离

数据问题修正后仍需核查设备疑点。现有数据查询与现场补采单独记账；当前未实施现场补采，不承诺试点、设备故障定位实绩或实际节能收益。

无付费 API

简单、可复核的工作流

允许的观测点位→数据质量 + 有效工况→风路 / 盘管证据→支持、反驳、下一步

策略只改变证据查询顺序；诊断规则、数值计算与证据池保持一致。本轮不增加复杂 Agent，也不优化本地模型。
