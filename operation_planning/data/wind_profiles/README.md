# Public wind profile provenance

The tracked `sd6_swcc_11_04.json` is an extracted, auditable metadata and table representation of the official SWCC-11-04 report. The raw PDF was downloaded locally for verification and is intentionally ignored by Git; use the `source_url`, `retrieved_utc`, and `source_sha256` in the JSON to obtain and verify the source before redistribution. The profile is a certified test system, not a China procurement recommendation.
