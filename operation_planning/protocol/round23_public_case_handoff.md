## 2. 资料到手之后的实际结论

| 检查项 | CU-BEMS，Chamchuri 5二层，2019 | 马德里Casa de la Villa，2024 |
|---|---|---|
| 实验性质 | 运营中真实办公建筑测量；不是故障注入或仿真 | 市政建筑实际能源监测；不是模型生成数据 |
| 时间/单位 | 525,600个分钟时间戳，60秒步长；kW功率、℃、%RH、lux | 12个唯一日历月的有功电量，kWh |
| 能否称电费单 | 无发票/电费金额；功率积分为派生量 | 无发票/电费金额；是月度监测记录 |
| 是否是模型相同范围 | 二层16个空调通道，多设备共享分区；部分大型压缩机 | 名称为一般电力总计量，缺空调分项 |
| 完整性 | 无重复/缺行时间戳，但测量值有缺失；16空调共同有效495,619分钟（94.295852%），全年完整空调通道0个 | 所选计量点12个月有限非负，合计214,828.03516 kWh |
| 原始空缺处理 | 保留未知，月度完整电量字段为空，周曲线不完整小时断开 | 所选记录均可解析；其他缺数文本计入缺项，未补0 |
| 必要元数据 | 分区面积、实际制冷能力/COP、设定点、日程、各设备服务区缺失；源时间戳无显式UTC偏移 | 房间、空调、日程、冷热/非空调分项、电费条款和实际计量边界缺失 |
| 准入判断 | 可用于实测用电形态和数据完整性展示；当前不可直接校准现有小空调房间模型 | 可用于连续12月实际电量展示；当前不可校准只算制冷除湿的模型 |

CU观测期间55.33 kW最大通道功率不是目录里小型空调的额定制冷量。论文对小机和大型压缩机的描述只能帮助识别范围，不能推导每一个通道对应的制冷量/COP。二层Zone2虽有多个小机通道，一个共享温湿度传感器也不能代表每台设备的独立服务区域。

CU源CSV每分钟一条功率值，没有证明其为整分钟平均。图中的电量采用明确的样本保持近似 `P_kW × 1/60h`，只积分有效分钟；不把该派生量当收费表计电量。本轮未转换为供需匹配LoadSeries，避免擅自确定时区和缺失负荷。

马德里数据的2024年行政建筑范围中，ID列305行均缺失，13行能耗是“无数据或信息不完整”的文字。选点从原先ID排序改为建筑名+传感器名排序，改动原因有记录；未用模型拟合表现选点。一般计量名字不等于已经核实完整建筑表计拓扑。

## 3. 可用于答辩的事实，以及应避免的说法

可使用：

- 真实建筑存在不同计量范围；一次校准必须明确对比的是空调、某一分区还是整栋楼。
- 已公开取得并核对525,600分钟空调相关记录，以及一栋市政建筑连续12个月实测电量；下载来源、许可、字段、缺测与哈希可追溯。
- 现有产品能按参考天气和用户假设进行逐时供需、成本与碳情景比较；已有功能证据继续成立。新截图只证明实际产品页面和已保存回放被展示。
- 不能仅因为一年总量接近就宣称空调模型准确，也不能把未知分钟等同停机。

不可使用：

- “真实建筑一年电费校准通过”“误差低于X%”“已经开展学校试点”“实测节省X元/吨碳”。本轮没有同范围预测或账单，因此精度/收益字段均为未得。
- 把186,741.808667 kWh不完整共同有效分钟积分称全年空调用电；把214,828.03516 kWh一般电力计量称空调用电。
- 把广州35㎡、2台空调的589 kWh参考回放说成马德里或曼谷实测模型输出。三者没有拼接。

## 4. 下一次可执行校准所需最小资料

优先选一个已建模的小型办公室空调分区，而非任意大楼总表。需要：连续12月或覆盖同一评价区间的空调分项kWh；明确位置与时区、起止时间；分区面积/层高/朝向/窗墙与主要围护；实际空调型号、台数和额定参数；使用时段、设定点、人数/设备热量的来源；缺测和设备更换记录。整楼账单可以辅助对账，但不能单独补足空调范围。

只有金额的账单不能直接用金额÷单价反推耗电。电量费、需量费和固定费用须分开，费用比较要核实生效电价与抄表区间。当前产品不覆盖全楼其他负荷或所有需量费，不能通过拟合系数默默吸收它们。

资料齐全后：先冻结计量范围、参数来源、可调参数、时间划分和评价口径，再生成同区间预测；月度实测/预测并列，所有月份作为分母。缺月时不报全年精度。校准集与验证集分开；本轮已经展开检查的数据不再宣称从未见过的独立验证。优先取得第二年度或独立分区以检验转移，不靠切窗扩大样本。当前没有设置一个未执行的误差门槛或伪造校准分数。
