# 储能与余电上网附加卡片的示例报价来源

本文件只记录回放用的公开参考和用户敏感性输入。它们不是采购合同、并网批复或现场收益承诺，不改变 S0–S3 主方案或推荐。

## 储能

- 来源：CNESA Datalink《2025年储能中标价格分析》
- URL：<https://www.esresearch.com.cn/report/info/detail/?id=6645>
- 页面报告的 2025 年均值：2 小时储能系统 **553.94 元/kWh**；2 小时储能 EPC **1043.82 元/kWh**。
- 回放拆分：`storage.quote.cny_per_kwh = 553.94`，`storage.quote.installation_cny_per_kwh = 489.88`（1043.82−553.94）。安装项按实际电池容量线性计算，以避免不同容量共用一个固定安装费。
- 该差额是为了满足模型的“设备／安装”字段拆分而作的示例分解；来源没有声称这两个数字属于同一份逐项采购报价，故输出保留 `source_note`，不把它包装为精确采购价。
- 年运维 300 元/年、寿命 10 年仍是用户演示假设；电池容量 0 不承担固定费用。

## 余电上网

- 政策来源：国家发展改革委《国家发展改革委 国家能源局关于深化新能源上网电价市场化改革 促进新能源高质量发展的通知》（发改价格〔2025〕136号）
- URL：<https://www.ndrc.gov.cn/xwdt/tzgg/202502/t20250209_1396067.html>
- 政策明确新能源上网电量全面进入电力市场、上网电价通过市场交易形成；因此不存在可以对所有广州项目直接套用的固定官方 0.25 元/kWh。
- 公开行业参考：华福证券《分布式光伏行业深度》<https://pdf.dfcfw.com/pdf/H3_AP202406141636236987_1.pdf> 曾以 0.25 元/kWh 作为市场化余电结算示例。该资料是行业敏感性参考，不是广东电网的结算批复。
- 回放使用 `export.price_cny_per_kwh = 0.25` 作为用户敏感性情景，仅用于展示余电收入的数量级；字段带有 `source_note`，不称为广东现行固定结算价。
- 第16节的简档小档将 `export.connection_cny = 0`，表示尚未取得并网／计量报价的粗算假设。它不代表并网资格或实际接入费用。
