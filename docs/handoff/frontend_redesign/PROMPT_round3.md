## 2. 本轮 6 件事

1. **区分“模型不可用”和“模型没理解”。** parse 返回 `failed` 时显示“本地大模型没能可靠理解这句话，请换个说法或直接修改表单”，并显示后端 `reason`（中文）；只有 `unavailable`/404/超时才显示“本地大模型暂不可用，已改用规则识别”并走规则。`failed` 时不要自动改用规则识别。
2. **显示被剔除的字段。** 若 parse 响应带 `dropped`（第 22 节契约：`[{field, reason}]`），在修改清单下方小字列出“已忽略：××（用户未提及）”。字段不存在时不显示。
3. **规则识别显示没识别的内容。** 离线规则识别后，把句子里没被任何规则命中的片段（按逗号/顿号/“和”切分）列为“没能识别：…”，提醒用户手动修改；同时让规则支持“预算改为60000元 / 预算改成6万 / 预算调到6万元”这类写法（与“预算60000元”等价）。
4. **示例条件与示例结果的电价口径一致。** 现在“从小档示例开始”把电价填成 0.66 元/kWh 固定价，而示例结果用的是官方分时电价档案，载入后重算费用会变。请从示例回放的请求（`request` / `input`）里读取电价档案和应用方式原样填入表单；回放里确实是固定价的才填固定价。验收：载入三档示例条件后直接计算，10 年总花费与示例结果一致（允许 ≤1 元的四舍五入差），把三档对比写进回交记录。
5. **修改清单里“原值”的显示。** 原值为默认值或处于“自动比选”模式时，不要显示“未填写”：年涨幅原值显示“0%（默认）”；光伏容量处于自动比选时显示“自动比选”。
6. **打印简报分页。** 表格跨页时重复表头（`thead{display:table-header-group}`、行不跨页拆分），减少末页大块留白（如去掉强制分页或把说明并到上一页）。用 Chromium 打印成 PDF 检查三档各一份，附逐页截图。
